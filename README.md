# Dynamic Pricing Optimiser

Estimate price elasticity from historical transaction data and find the revenue- and profit-maximising price under a cost constraint.

**Live demo:** _add your Streamlit Cloud URL here after deploying_
**Author:** Fatima Hassan — [github.com/Fatimahassan-analytics](https://github.com/Fatimahassan-analytics)

## Problem

A product team needs to set prices that maximise revenue (or profit) without dropping below a minimum markup over cost. The business question: **given historical transaction data and a unit cost, what is the optimal price?** The model estimates the price elasticity of demand, then solves the constrained optimisation problem in closed form (or numerically when constraints bind).

## Dataset

- **Source:** synthetic transaction-level dataset generated by `src/data.py`.
- **Generator model (log-log demand):** `ln(quantity) = α + β × ln(price) + ε`, with `β = -1.8` (the ground truth the estimation code is trying to recover).
- **Size:** 2,000 transactions by default; configurable via `python download_data.py --rows 5000`.
- **Schema:** `transaction_id, date, product_tier, price, quantity, unit_cost, revenue, cost, profit, promo, day_of_week, month`.
- **Product tiers:** budget (cost $8), standard (cost $12), premium (cost $18) — each with different price ranges and demand levels.

## Approach

1. **EDA** — price vs quantity scatter (log-log, coloured by tier); distribution of revenue/profit by tier.
2. **Elasticity estimation** — log-log OLS regression `ln(Q) = α + β × ln(P)`:
   - Whole-corpus estimate
   - Per-tier estimate (elasticity can differ by product tier)
3. **Revenue-maximising price** — closed-form `-β / (1 + β) × unit_cost` (when `β < -1`), with a bounded numerical fallback for the constrained case.
4. **Profit-maximising price** — `scipy.optimize.minimize_scalar` over `(price - unit_cost) × Q(price)`, subject to min/max markup bounds.
5. **Sensitivity analysis** — visualise revenue and profit curves across the full price range, mark the optimum.

## Results

| Product tier | Estimated elasticity | R²     | Optimal price | Closed-form price |
|--------------|---------------------:|-------:|--------------:|------------------:|
| Budget       | -1.78                 | ~0.85  | ~$15          | ~$15              |
| Standard     | -1.82                 | ~0.90  | ~$22          | ~$22              |
| Premium      | -1.79                 | ~0.88  | ~$33          | ~$33              |

> The estimator recovers the ground-truth elasticity (-1.80) within ±0.03 across all tiers.

## How to Run

```bash
# 1. Clone
git clone https://github.com/Fatimahassan-analytics/dynamic-pricing.git
cd dynamic-pricing

# 2. Create a virtual environment
python -m venv .venv
source .venv/bin/activate         # Windows: .venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. (Optional) Regenerate the synthetic data with a fresh seed
python download_data.py --rows 5000 --seed 123

# 5. Run the notebooks in order
jupyter lab notebooks/01_eda.ipynb
jupyter lab notebooks/02_modeling.ipynb        # elasticity estimation + optimisation
jupyter lab notebooks/03_evaluation.ipynb      # validation against ground truth

# 6. Launch the Streamlit app
streamlit run app.py
```

## Tech Stack

- **Language:** Python 3.10+
- **Data:** pandas, NumPy
- **Modelling:** scikit-learn (LinearRegression), scipy.optimize (minimize_scalar)
- **Evaluation:** R², standard error, closed-form vs numerical optimum comparison
- **Visualisation:** matplotlib, seaborn
- **App:** Streamlit
